项目说明：旨在开发一套适用于嵌入式 ARM/Linux 平台的实时音视频采集与流媒体传输系统，实现 USB 摄像头采集、本地 GUI 预览、图像处理、视频录制以及 RTP/UDP 网络推流，并提供配套服务端完成 H.264 解码显示。
技术栈：C++，Qt 5，V4L2，OpenCV，FFmpeg，x264，RTP/UDP，Socket 网络编程，ARM-Linux-GCC 交叉编译
技术亮点：
.V4L2 视频采集：基于 Linux V4L2 接口完成 USB 摄像头初始化、YUYV 格式配置、帧率设置和多缓冲区 mmap 映射，通过缓冲区轮转机制实现稳定实时采集。
.图像处理功能实现：结合 OpenCV 实现灰度化、二值化、Canny 边缘检测等图像处理算法，并支持在界面中动态开启/关闭处理效果，满足实时预览与图像分析需求。
.嵌入式性能优化：使用定点整数完成 YUYV 到 RGB 转换，减少浮点运算开销，降低 CPU 占用。
.视频录制与帧率修正：实现摄像头画面录制功能，基于时间戳统计实际采集帧率，并在保存视频时进行重复帧补偿，避免录制视频出现播放过快或音画节奏异常问题。
.H.264 编码与 RTP 推流：基于 FFmpeg/x264 完成 H.264 编码，手动构造 RTP 包并通过 UDP 推流。
.服务端接收与解码显示：设计 RTP/UDP 接收端，完成数据包序号解析、丢包检测、分片重组和 H.264 解码
