# Image_Process
基于 i.MX6ULL 的嵌入式音视频采集与流媒体系统。支持 USB 摄像头实时采集、本地 GUI 显示、图像处理、H.264 编码录制及 RTP/UDP 网络推流，并提供配套服务端接收解码显示。

主要功能

V4L2 驱动采集（YUYV 格式），多缓冲轮转消除画面撕裂

Qt 界面实时预览，可调节亮度、对比度等摄像头参数

独立线程实现灰度化、二值化、Canny 边缘检测，支持动态开关

基于时间戳的智能录制，自动修正帧率避免视频快进

FFmpeg 软编码 H.264，手动 RTP 分包通过 UDP 发送

服务端接收 RTP 包、解码并以 BGRA 格式渲染


技术特点

定点整型 YUYV→RGB 转换，降低 CPU 占用

多线程架构分离采集、处理、编码，保障 UI 流畅

针对单核 Cortex-A7 优化，320×240@25fps 稳定运行

跨线程 Qt 信号槽传递图像，零额外拷贝

适用于嵌入式 Linux 应用、音视频开发、Qt/C++ 项目学习与参考。
